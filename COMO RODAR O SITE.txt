  PRIMEIRA VEZ APENAS — Instalar dependências

  Na pasta "journey-backend", rode:
    pip install -r requirements.txt

  Na pasta "journey-frontend", rode:
    npm install

  Terminal 1 — Backend (servidor):

    Entre na pasta "journey-backend" e rode:
      uvicorn main:app --reload

  Terminal 2 — Frontend (site):

    Entre na pasta "journey-frontend" e rode:
      npm run dev
